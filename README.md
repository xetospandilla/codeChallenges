# Coding Challenges

Repositorio de **repaso y práctica de JavaScript** (y algo de SQL) con ejercicios de programación y pequeños programas creados durante el Grado en Tecnologías Interactivas (UPV).

## Propósito

- Practicar conceptos de JavaScript: funciones, arrays, objetos, promesas, `async/await`, gestión de errores y buenas prácticas.
- Preparar exámenes de la asignatura (repaso final con callbacks, promesas, testing, SQL y servidores básicos).
- Resolver retos variados (desafíos "claudeChallenges") por mi cuenta.

## Estructura

```text
javaScript/
├── changeCalculator/            Calculadora de cambio con monedas.
├── claudeChallenges/            Retos de programación (challenge-01 … 05).
├── passwordValidator/           Validador de contraseñas (reglas de validación).
├── vocales/                     Contador de vocales en un texto.
├── arraysRPG/                   Minijuego RPG con arrays (persistencia con SQLite).
├── repasoExamenFinal/           Repaso completo: callbacks, promesas, arrays, testing,
│                                consultas SQL y servidores con Node.js.
└── correcciones-y-buenas-practicas.js   Correcciones de ejercicios con mejoras comentadas.
```

## Contenido destacado

- **arraysRPG** — pequeña aventura RPG por consola (Node.js) que gestiona un gremio de personajes y guarda datos con SQLite.
- **repasoExamenFinal** — batería de ejercicios de repaso: desde callbacks y promesas hasta consultas SQL y servidores con Express.
- **claudeChallenges** — retos breves para practicar lógica y manipulación de datos (arrays, objetos).

## Lenguajes

- JavaScript (Node.js).
- SQL (consultas de repaso en `repasoExamenFinal`).

## Nota

Repositorio secundario de práctica: los ejercicios son formativos y reflejan una fase de aprendizaje.
